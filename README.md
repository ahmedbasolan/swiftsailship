# Swift Sail Shipping LLC Website

A modern website for Swift Sail Shipping LLC — a Dubai-based freight and logistics company. Built with Next.js 16, Tailwind CSS v4, and Framer Motion.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Landing page with hero, services overview, and CTA |
| `/about` | Company information and team |
| `/services` | Freight and logistics service offerings |
| `/how-it-works` | Step-by-step process explanation |
| `/get-quote` | Quote request form |
| `/blog` | Company blog / news |
| `/privacy` | Privacy policy |
| `/terms` | Terms of service |

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router) |
| Styling | Tailwind CSS v4 |
| Animation | Framer Motion |
| Language | TypeScript |
| UI Components | Radix UI + shadcn/ui |

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |
